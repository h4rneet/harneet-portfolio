Design Projects

The MakerDrop

Product Design ✦ UX Research ✦ Design Thinking

The MakerDrop is a collaborative design project aiming to increase the discoverability and acessibility of the UTM Makerspace (Open Design Collaboratory). We iterated through the steps of the Design Thinking process and developed the MakerDrop, a vending machine that raises awareness about the MakerSpace to students around campus. The MakerDrop was built with hands-on fabrication tools available in the lab.


Tools: Cricut Maker 4 ✦ xTool Laser Cutter ✦ 3D Printer ✦ Canva

Campus Calm

Front-End Web Development ✦ UI/UX Design ✦ Interactive Media Design ✦ Graphic Design

Campus Calm is an interactive web-based multimedia experience designed to provide quick, low-pressure mental-health support for university students. The goal is to create a simple, accessible space for students to rest through meaningful interactions like journalling, mindful breathing, or ambient sound that can be used anywhere and anytime.

Tools: HTML/CSS/JS ✦ Figma ✦ GitHub

Berry Blitz

✦ Game Development ✦ Python Programming ✦ Creative Coding ✦ Game Asset Design

Berry Blitz is a pixel-style platformer game where the user plays as a bear who is collecting all of the strawberries while avoiding the blueberry enemies, before all three lives run out.


Tools: Python ✦ Pygame ✦ ibisPaintX

Strawbeary Hollow

✦ Game Development ✦ 3D Modelling ✦ Immersive Environment Design ✦ Graphic Design

Strawbeary Hollow is a 3D immersive environment where the user plays as a bear named Berry who returns to her family's cottage to take a break from her stressful university life. The goal is to walkthrough the environment, interact with the various objects that tell stories about Berry's life, and focus on the present.


Tools: Autodesk Maya ✦ Unity ✦ Adobe Photoshop ✦ ibisPaintX
